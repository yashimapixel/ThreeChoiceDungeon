# 三択ダンジョン（ThreeChoiceDungeon）

三つの選択肢を選びながら地下百階を目指す、白黒＋赤のホラー風ファンタジーRPG。
Godot 4.7 / 論理解像度 360×640（縦画面）/ Android 対応。

- **配色**：6色（黒・暗いグレー・明るいグレー・白／明るい赤・暗い赤）。スチルも画面もこの6色のみ。
- **画面比率**：9:16より縦長の端末では論理画面が縦に伸び、各画面をヘッダー（安全領域の上端）・センター・フッター（安全領域の下端）に分けて配置（ノッチ・角丸は安全領域で回避）。9:16より横長では左右に余白が付くだけ。
- **グリッド**：UI要素は8×8ピクセルのグリッドに整列。

`release/ThreeChoiceDungeon-v1.9.0.apk`（arm64-v8a / armeabi-v7a, 署名済み）

## ゲームの仕組み

- **3つのパラメータ**：肉体・精神・運命。どれか一つでも 0 になるとゲームオーバー。
- **1階ごとに1イベント**：ピクセルアートの情景と文章、3つの選択肢。選んだ結果にも、結果ごとに描き下ろしたスチル（全516種）が表示される。スチルはゲームと同じ等倍 336×200 ピクセル（仮画像・プログラム生成）。
  - `［肉体判定 成功率 62%］` のような判定つき選択肢は、現在の能力値・所持品・深さで成功率が変わる。
  - `〈ロープ〉` のような所持品が必要な選択肢。持っていなければ、選べない状態で表示される（所持品の価値がわかる）。
  - 一度見た結果は「成功→肉体-2／失敗→肉体-6」のように選択肢に表示される（現在の階層での値）。
  - 選択の結果、パラメータの増減、所持品（フラグ）の入手・喪失、近道（階層スキップ）が起こる。
- **フラグ**：所持品として表示されるもの（たいまつ・聖水・黒い犬・呪い…）と、周回をまたいで残るもの（騎士との出会い、メモの続きなど）がある。フラグで発生するイベントや、結果が変わるイベントがある。
- **所持品は個数で持てる**（薬瓶×2など）。物語系の所持品（少女の霊・騎士の誓い・王冠・魔女の印・第三の眼・黒い犬・銀の剣）は1つまで。
- **所持品の効果**：判定ボーナス（犬・剣・王冠・第三の眼など）、呪い（運命判定-15%）、赤いお守り（1つにつき一度、死を免れる）、薬瓶（タップで肉体回復）。
- **深さ**：深く潜るほどダメージ・回復が大きくなり、判定も厳しくなる。地下25・50・75階には門番がいて、地下100階が最深部（結末は5種類）。
- **周回要素**
  - 探索中に拾う「金貨」はその探索の中だけで使う（渡し守や商人への支払いなど）。
  - ゲームオーバー時、到達階層と残った金貨が「魂の欠片」に換わる（持ち越し通貨）。
  - 魂の欠片で肉体・精神・運命の初期値を強化（Lvが上がるほど費用増）。
  - 累計で潜った階数に応じて新しいイベントが解放される（最初は29種類、全100種類）。
  - 地下25・50・75階の門番を越えると、次回から魂の欠片（20／50／100）を払って地下26・51・76階から開始できる。途中から始めた場合、深さの報酬は開始階より先に進んだ分だけ。
  - ゲームオーバー時、リワード広告を見ると得た魂の欠片が2倍になる（現在はダミー広告。`scripts/ads.gd` を広告SDKに差し替える）。
  - 地下100階に到達するとクリア、無限迷宮（エンドレスモード）が解放される。地下101階より先にはエンドレス専用の出来事（8種）があり、「王の使者」で地上へ帰還（自発的に探索を終える）できる。
  - 直前2回の探索で見た出来事は出にくくなる（序盤の繰り返し対策）。
- 音楽：言葉のない子守唄（オルゴール／ハミング）、深さで変わる探索曲（上層・深層・最深層）、門番、エンディング。タイトル右上で音のON/OFF。
- 探索中は毎階オートセーブ。アプリを閉じてもタイトルの「続きから」で再開できる。

## 物語（ネタバレ注意）

**芯：お別れを言えなかった親子。** 3年前の流行り病で、王は都を守るため「罹患者は隔離塔へ。例外は認めない」と命じた。熱を出した最後の夜、子守唄を歌う母の腕から、王女は王の命を受けた騎士の手で引き離され、塔でひとり亡くなった。おやすみもさよならも言えなかった王妃は、迷宮の底の「願いを喰らうもの」に「もう二度と離れたくない」と願い、迷宮と融合した。娘の霊は母の内側をさまよい、母は言葉を喰われ、言葉のない子守唄だけが残った。騎士は罪を償うため底へ挑んで敗れ、亡霊になった。孤独な王は毎晩、迷宮の入口に手紙を投げ入れ、「真実を明らかにできる勇者を求む」と布告した。

### 章立て（深さ＝章、門番＝章の区切り）
| 章 | 階 | 内容 |
| --- | --- | --- |
| 第一章　降下（起） | 1〜25 | 子守唄、少女、亡霊の騎士との出会い。迷宮の決まり事（写し取り）を知る |
| 第二章　弔い（承） | 26〜50 | メモ、作り物の墓、揺りかご、魔女の証言で、悲劇がにじむ |
| 第三章　引き離された夜（転） | 51〜75 | 命令書、隔離塔、騎士の告白、王の手紙。自分が何度も連れ戻されていることも知る |
| 第四章　子守唄（結） | 76〜100 | 母の体内、あの夜の病室。底で何を願うかを選ぶ |

各章の重要イベントは出やすく、章の終わり4階で未見なら必ず発生する。章の始まりに章タイトルを表示。見つけた真相は「手記」に章ごとに記録される。結末の後に、真相をどこまで知ったかで変わる「後日談」（王への報告）がある。

### 迷宮の中の「場違いなもの」の建て付け
1. **写し取られたもの**：迷宮は王妃の記憶を写し取って形にする（揺りかご、作り物の墓、命令書、色の抜けた王都、病室）。写しは「どこか少しだけ間違っている」（木目が脈打つ、文字が滲むのに一行だけ鮮明、墓に亡骸がない）。
2. **呑み込まれたもの**：王都の地下へ広がる迷宮が地盤ごと沈めた実在の場所（隔離塔）。
3. **落ちてきた／持ち込まれたもの**：王妃のメモ、挑戦者の亡骸と装備、王が毎晩投げ入れる手紙。

登場人物に固有名はなく、紋章・子守唄・呼び方で関係が示される。説明は避け、文書や落書き、ひと言でにおわせる。

### 主な分岐
- **少女の墓**：成仏させると、その探索では少女は消える（母との再会はなくなるが、魂は天へ）。連れていけば底で母と会える。
- **薄れゆく亡霊（騎士）**：誓いを持っていれば剣に宿って共に行く。眠らせると結末に関わらない。

### 結末（7種）
| 結末 | 条件 | 内容 |
| --- | --- | --- |
| 還る光（真） | 少女＋騎士の誓い | 騎士と眼を討つ。母は3年遅れの子守唄を最後まで歌い、娘に「おやすみ」と別れを告げる |
| 母と娘 | 少女 | 少女が歌詞をのせ、母の声が戻る。二人は「おやすみ」を言い交わして還る |
| 果たされた誓い | 騎士の誓い | 騎士と眼を討ち、母を解放する |
| 願いの終わり | 真相を知っている | 「お別れを言わせてあげて」と、他者のために願う |
| 闇を斬る者・生還・底の主 | 誰でも | 真相を知っていると苦い余韻が加わる |

## ファイル構成

| パス | 内容 |
| --- | --- |
| `data/events/tier1〜4.json` | 本編の全100イベント（文章・選択肢・結果・解放条件） |
| `data/events/endless.json` | エンドレス専用イベント（8種） |
| `data/balance.json` | バランス調整値（ゲームとシミュレータで共有） |
| `scripts/game.gd` | ゲームルール・セーブ（autoload `Game`） |
| `scripts/ads.gd` | リワード広告の窓口（autoload `Ads`）。今はダミー広告 |
| `scripts/main.gd` | 全画面のUI（コードで構築）、効果音（プロシージャル生成） |
| `art/events/*.png` | イベント画像（336×200 等倍）。`tools/gen_art.py` で生成 |
| `fonts/` | PixelMplus12（M+ FONT LICENSE） |
| `tools/gen_art.py` | 3色ピクセルアート生成（`python3 tools/gen_art.py --sheet out.png` で一覧画像） |
| `tools/gen_results.py` | 結果スチル生成（専用の描き下ろし36種＋場面指定による480種） |
| `tools/result_scenes.py` | 結果ごとの場面指定（背景・主人公のポーズ・小物・演出を1行で記述） |
| `tools/scene_kit.py` | 場面指定の描画部品（主人公の約20ポーズ、小物、演出） |
| `art/results/*.png` | 結果スチル（`<イベント>_<選択肢>_<r/ok/ng>.png`） |
| `tools/gen_audio.py` | 音楽・環境音の作曲／合成（numpy＋ffmpeg）。子守唄、深さ別の探索曲、門番、エンディング等 |
| `audio/*.ogg` | 生成された音楽（シームレスループ） |
| `tools/gen_icon.py` | アプリアイコン生成 |
| `tools/sim.py` | バランスシミュレータ（ルールを Python で再現） |
| `tools/test_runs.gd` | ヘッドレスでランダムに数百回プレイするテスト |
| `tools/screenshots.gd` | 各画面のスクリーンショット生成（xvfb 上で実行） |

### イベントデータの書式（抜粋）

```jsonc
{"id":"e011","t":"落とし穴","a":"corridor:pit",   // a = 背景:小物（画像生成用）
 "min":1,"max":60,"w":9,                          // 出現階層・重み
 "u":0,                                           // 解放条件：累計階数 / "m:メタフラグ"
 "req":["girl"],"no":["dog"],                     // 発生に必要/禁止のフラグ
 "d":"本文", "dx":[{"req":["torch"],"d":"追記"}],
 "c":[{"t":"ロープを使って渡る","req":["rope"],"r":{"d":"結果","b":-1}},
      {"t":"跳ぶ","chk":"b","p":0.6,"ok":{...},"ng":{...}}]}
// 結果: b/m/f=増減, mb/mm/mf=最大値増減, g=金貨, set/clr=フラグ, meta=永続フラグ, skip=近道
```

## ビルド

1. Godot 4.7.2 と Android エクスポートテンプレートを用意。
2. エディタ設定で Android SDK（`platform-tools/adb` と `build-tools/*/apksigner`）と JDK 17+ を指定。
3. リリース署名の鍵を環境変数で渡してエクスポート：

```sh
export GODOT_ANDROID_KEYSTORE_RELEASE_PATH=/path/to/release.keystore
export GODOT_ANDROID_KEYSTORE_RELEASE_USER=<alias>
export GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD=<password>
godot --headless --export-release "Android" build/ThreeChoiceDungeon.apk
```
